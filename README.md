# Central de Macros para Suporte

Uma página simples para agilizar atendimentos de suporte técnico, reunindo mensagens prontas para início e encerramento de chats.

## Recursos

- Duas abas: **Início** e **Encerramento**.
- Dez variações de mensagem em cada etapa.
- Saudação automática: usa “Bom dia” ou “Boa tarde” conforme o horário.
- Copie uma mensagem clicando em seu cartão.
- Botão para copiar uma frase aleatória da aba atual.
- Layout responsivo para desktop e celular.

## Como usar

Não há instalação necessária. Clone ou baixe o projeto e abra o arquivo `index.html` no navegador.

```bash
git clone <url-do-repositorio>
cd Macros_Site
```

## Tecnologias

- HTML5
- CSS3
- JavaScript puro

## Estrutura

```text
├── index.html   # Estrutura da página
├── styles.css   # Estilos e responsividade
└── script.js    # Mensagens, abas e cópia para a área de transferência
```
